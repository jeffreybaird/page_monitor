Page Monitor modifies the bundled SDK at build time in vite.config.ts:
- storage.sync operations use storage.local;
- network calls use an eight-second AbortSignal timeout;
- restoration waits for popup creation and propagates failures.
No changes are made to the installed dependency files. Reproducible source and
build instructions accompany the submission source archive.
